# AI Student Service

## Project Description
AI Student Service is a simple AI chatbot designed to help students by answering common student-related questions.

## Features
- Answers student-related questions
- Provides quick responses
- Simple and easy to use
- Helps students get basic information

## Technology Used
- Python
- AI Chatbot

## How to Run
1. Open the project in VS Code.
2. Run the Python code.
3. Enter a student question.
4. The chatbot will provide an answer.

## Future Scope
More questions and student-related information can be added to make the chatbot more useful.

## Conclusion
AI Student Service is a simple chatbot project that helps students get answers to common questions quickly.
